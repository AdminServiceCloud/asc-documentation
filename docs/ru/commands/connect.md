# 🔗 asc connect

Подключает ноду к платформе AdminService.Cloud по одноразовому токену
регистрации, выданному в панели.

## Использование

```
sudo asc connect <ТОКЕН> [--url <URL>]
```

| Аргумент | Значение |
|---|---|
| `<ТОКЕН>` | Одноразовый токен регистрации из панели. Только буквы, цифры, `-` и `_` |
| `--url <URL>` | Базовый URL платформы, по умолчанию `https://adminservice.cloud` |

Требует root: токен записывается в `/etc/asc/platform.token` с правами `0600`,
а URL платформы — в секцию `[platform]` файла `/etc/asc/config.toml`.

То же самое происходит автоматически, если демон устанавливается с токеном:

```
curl -fsSL https://raw.githubusercontent.com/AdminServiceCloud/asc-daemon/main/install.sh \
  | sudo bash -s -- --silent --token <ТОКЕН>
```

`asc connect` нужен, чтобы подключить ноду, установленную раньше без платформы,
и чтобы повторить регистрацию, если платформа была недоступна.

Токен срабатывает ровно один раз. Если ноду нужно зарегистрировать заново,
выпустите новый токен в панели.
