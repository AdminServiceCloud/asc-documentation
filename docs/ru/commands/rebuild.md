# 🧱 asc rebuild

Пересобрать приложение без смены версии: заново скачать или собрать его образы
и принудительно пересоздать контейнеры. То же самое, что
[`asc app rebuild`](/ru/commands/app#rebuild).

## Использование

```
asc rebuild <app> [--service <сервис>] [--no-pull]
```

- **`app`** — id или имя приложения (позиционный, обязателен).
- **`--service <сервис>`** — пересобрать только один сервис docker
  compose-приложения; остальные сервисы не трогаются. Подразумевает `--no-pull`.
- **`--no-pull`** — не подтягивать исходники перед сборкой. По умолчанию
  подтягивается ссылка, за которой приложение уже следит (HEAD его ветки;
  у приложения, закреплённого на теге, коммит не меняется — тег не двигается).

Только docker- и docker compose-приложения — у systemd- и process-приложений
пересобирать нечего. Образы скачиваются (с любым тегом) или пересобираются на
свежем базовом образе, пока старые контейнеры работают, и только потом
контейнеры пересоздаются. Состояние сохраняется: остановленное приложение
остаётся остановленным, но его контейнеры пересозданы. Неудачная пересборка
compose-приложения возвращает прежние коммит, теги образов и контейнеры.

```
$ asc rebuild shop
Приложение 'shop' пересобрано: db, web
  коммит: 3f2a9c1 → 8d41e07
```
