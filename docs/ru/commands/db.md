# 🗃️ asc db

Локальная база демона: SQLite-индекс установленных приложений с зеркалом
каталога `.asc/` каждого приложения (`meta.json`, `settings.json`,
`compose.override.yaml`, …). `asc ls` и API демона берут список приложений из
неё, а не обходом `/asc/apps`; источником истины остаются файлы. Что в ней
хранится и как она синхронизируется — в [Управлении приложениями](/ru/cli/app-management).

Только для root: база охватывает все приложения ноды. Если демон запущен,
команды идут через него (`/v1/db`), иначе работают с файлом напрямую.

## Использование

```
asc db <действие>
```

### status

```
asc db status
```

Показать путь к базе, версию схемы, каталог приложений, сколько в ней
приложений и файлов `.asc/`, её размер, когда её последний раз пересобирали и
сверяли и работает ли слежение за файлами.

### verify

```
asc db verify
```

Сверить базу с файлами приложений — только `stat`, содержимое читается лишь
у изменившихся — и исправить расхождения. Печатает, сколько приложений
проверено, добавлено, обновлено и удалено. Демон делает это сам раз в минуту.

### rebuild

```
asc db rebuild
```

Собрать базу заново из файлов приложений. В обычной работе не нужно —
отсутствующая или повреждённая база пересобирается сама при старте демона, —
но безопасно всегда.
