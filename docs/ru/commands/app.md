# 📱 asc app

Управление приложениями: своими; под `sudo` — чужими тоже.

## Использование

```
asc app <действие> [аргументы]
```

### list

Список приложений. Root видит все приложения всех пользователей,
сгруппированные по владельцу.

### info

```
asc app info <id>
```

Показать детали приложения.

### disk

```
asc app disk [id]
```

Показать использование диска: полоска квоты (если задана) и разбивка по
образу, репозиторию, данным и кастомным томам. Без id: суммарное место,
занятое всеми приложениями, затем использование каждого, по убыванию.
Сокращённая версия для всего парка приложений: [`asc disk`](/ru/commands/disk).

### ports

```
asc app ports [id]
```

Показать опубликованные порты (host==container) с транспортом. Без id:
таблица по всем приложениям и их портам. Сокращённая версия:
[`asc ports`](/ru/commands/ports).

### clone

```
asc app clone <id> [--name <имя>]
```

Клонировать экземпляр приложения (данные, env, настройки) в новый.

- **`--name <имя>`** — имя клона (пропускает интерактивный запрос).

### install

```
asc app install <spec> [--source <имя>] [--name <имя>] [--branch <ветка> | --tag <тег>] [--path <подкаталог>] [--image | --build]
```

Установить приложение из реестра или git-репозитория — то же самое, что
верхнеуровневая [`asc install`](/ru/commands/install), см. её страницу по всем флагам.

### attach

```
asc app attach <id>
```

Подключиться к консоли приложения — то же самое, что верхнеуровневая
[`asc attach`](/ru/commands/attach).

### upgrade

```
asc app upgrade <spec>
```

Обновить приложение до новой версии — то же самое, что верхнеуровневая
[`asc upgrade`](/ru/commands/upgrade).

### start

```
asc app start <id> [-d|--detach]
```

Запустить приложение и подключиться к его консоли (Docker-приложения,
интерактивный терминал).

- **`-d`, `--detach`** — запуск в фоне без подключения к консоли.

### stop

```
asc app stop <id>
```

### restart

```
asc app restart <id>
```

### logs

```
asc app logs <id> [-n|--tail <n>]
```

Показать логи приложения.

- **`-n`, `--tail <n>`** — число последних строк. По умолчанию: `100`.

### settings

```
asc app settings <id>
```

Интерактивно отредактировать настройки приложения, заданные в `asc.settings.yaml`.

### remove

```
asc app remove <id> [-y|--yes]
```

Удалить приложение и все его данные.

- **`-y`, `--yes`** — подтвердить удаление без запроса.
