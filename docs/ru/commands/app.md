# 📱 asc app

Управление приложениями: своими; под `sudo` — чужими тоже.

## Использование

```
asc app <действие> [аргументы]
```

### list

Список приложений. Root видит все приложения всех пользователей,
сгруппированные по владельцу.

### info

```
asc app info <id>
```

Показать детали приложения.

### disk

```
asc app disk [id]
```

Показать использование диска: полоска квоты (если задана) и разбивка по
образу, репозиторию, данным и кастомным томам. Без id: суммарное место,
занятое всеми приложениями, затем использование каждого, по убыванию.
Сокращённая версия для всего парка приложений: [`asc disk`](/ru/commands/disk).

### ports

```
asc app ports [id]
```

Показать опубликованные порты (host==container) с транспортом. Без id:
таблица по всем приложениям и их портам. Сокращённая версия:
[`asc ports`](/ru/commands/ports).

### clone

```
asc app clone <id> [--name <имя>]
```

Клонировать экземпляр приложения (данные, env, настройки) в новый.

- **`--name <имя>`** — имя клона (пропускает интерактивный запрос).

### install

```
asc app install <spec> [--source <имя>] [--name <имя>] [--branch <ветка> | --tag <тег>] [--path <подкаталог>] [--app <приложение стека>] [--force] [--image | --build]
```

Установить приложение из реестра или git-репозитория — то же самое, что
верхнеуровневая [`asc install`](/ru/commands/install), см. её страницу по всем флагам.

### attach

```
asc app attach <id>
```

Подключиться к консоли приложения — то же самое, что верхнеуровневая
[`asc attach`](/ru/commands/attach).

### upgrade

```
asc app upgrade <spec>
```

Обновить приложение до новой версии — то же самое, что верхнеуровневая
[`asc upgrade`](/ru/commands/upgrade).

### rebuild

```
asc app rebuild <app> [--service <сервис>] [--no-pull]
```

Пересобрать приложение без смены версии: заново скачать или собрать образы и
принудительно пересоздать контейнеры — то же самое, что верхнеуровневая
[`asc rebuild`](/ru/commands/rebuild), подробности на её странице.

- **`--service <сервис>`** — только один сервис docker compose-приложения
  (подразумевает `--no-pull`).
- **`--no-pull`** — не подтягивать сначала ссылку, за которой следит приложение.

### services

```
asc app services <id>
```

Показать сервисы docker compose-приложения: состояние, health, образ и
опубликованные порты первого контейнера каждого сервиса (`missing` — у сервиса
нет контейнера).

### start

```
asc app start <id> [-d|--detach] [--service <сервис>] [--force]
```

Запустить приложение и подключиться к его консоли (Docker-приложения,
интерактивный терминал).

- **`-d`, `--detach`** — запуск в фоне без подключения к консоли.
- **`--service <сервис>`** — запустить один сервис docker compose-приложения.
- **`--force`** — запустить, даже если на обязательные вопросы первичной
  настройки ещё нет ответа; решение запоминается, пока на них не ответят.

### stop

```
asc app stop <id> [--service <сервис>]
```

- **`--service <сервис>`** — остановить один сервис docker compose-приложения;
  следующий старт, пересборка или обновление приложения поднимут его снова.

### kill

```
asc app kill <id> [--service <сервис>]
```

Принудительная остановка: SIGKILL без корректного завершения (для приложения,
которое зависло при остановке).

- **`--service <сервис>`** — убить один сервис docker compose-приложения.

### restart

```
asc app restart <id> [--service <сервис>] [--force]
```

- **`--service <сервис>`** — перезапустить один сервис docker compose-приложения.
- **`--force`** — перезапустить, даже если на обязательные вопросы первичной
  настройки ещё нет ответа, как `start --force`.

### logs

```
asc app logs <id> [-n|--tail <n>] [-t|--timestamps] [--service <сервис>]
```

Показать логи приложения.

- **`-n`, `--tail <n>`** — число последних строк. По умолчанию: `100`.
- **`-t`, `--timestamps`** — метка времени перед каждой строкой.
- **`--service <сервис>`** — один сервис docker compose-приложения, без
  префикса имени сервиса.

### settings

```
asc app settings <id>
```

Интерактивно отредактировать настройки приложения, заданные в `asc.settings.yaml`.

### remove

```
asc app remove <id> [-y|--yes]
```

Удалить приложение и все его данные.

- **`-y`, `--yes`** — подтвердить удаление без запроса.
