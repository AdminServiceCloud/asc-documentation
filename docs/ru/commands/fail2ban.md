# 🚫 asc fail2ban

fail2ban ноды: установка, включение и выключение jail'ов, их настройка,
просмотр, добавление и снятие банов. Баны исполняются через nftables в
собственной таблице fail2ban. Какую конфигурацию пишет демон — на странице
модуля [🚫 fail2ban](/ru/cli/fail2ban).

## Использование

```
asc fail2ban <действие> [аргументы]
```

fail2ban управляется root — запускайте команды через `sudo`. Они обращаются к
работающему демону; сначала запустите его: `sudo asc service start`.

### status

```
asc fail2ban status
```

Показывает версию, запущен ли fail2ban, значения по умолчанию (время бана, окно
подсчёта, число попыток, игнорируемые адреса), последнюю ошибку и jail'ы со
счётчиками.

### install

```
asc fail2ban install
```

Ставит пакет, пишет конфигурацию демона (`/etc/fail2ban/jail.d/asc.local`) и
запускает службу с jail'ом `sshd`.

### uninstall

```
asc fail2ban uninstall [--purge]
```

Удаляет fail2ban и файл конфигурации демона. **`--purge`** удаляет и состояние
демона.

### settings

```
asc fail2ban settings [--bantime <время>] [--findtime <время>] [--maxretry <n>] [--increment <bool>] [--add-ignore <адрес>]... [--remove-ignore <адрес>]...
```

Меняет значения по умолчанию для всех jail'ов. Время — в синтаксисе fail2ban:
`90`, `10m`, `1h`, `1d`, `1w`; `--bantime -1` банит навсегда.

- **`--bantime`** — на сколько банить (по умолчанию `1h`).
- **`--findtime`** — окно, в котором считаются неудачи (по умолчанию `10m`).
- **`--maxretry`** — число неудач в окне, после которого бан (по умолчанию 5).
- **`--increment`** — банить повторных нарушителей всё дольше.
- **`--add-ignore`**, **`--remove-ignore`** — IP и CIDR, которые никогда не
  банятся. Loopback игнорируется всегда.

Конфигурация, которую fail2ban отверг, не сохраняется: прежний файл остаётся, а
ошибка печатается.

```
sudo asc fail2ban settings --bantime 1d --add-ignore 203.0.113.0/24
```

### jails

```
asc fail2ban jails
```

Список jail'ов, которые умеет запускать демон: включён ли каждый и работает ли,
текущие неудачи и баны, переопределённое число попыток. Jail'ы, читающие логи
веб-сервера, сообщают об этом, пока веб-сервер не установлен.

### enable

```
asc fail2ban enable <jail>
```

Включает jail. Известные: `sshd`, `recidive`, `nginx-http-auth`,
`nginx-botsearch`, `nginx-limit-req`; три nginx-jail'а требуют модуль
веб-сервера.

### disable

```
asc fail2ban disable <jail>
```

Выключает jail.

### tune

```
asc fail2ban tune <jail> [--maxretry <n>] [--bantime <время>] [--findtime <время>] [--port <порты>] [--logpath <путь>]
```

Переопределяет настройки одного jail'а. **`--port`** принимает порты,
диапазоны или имена служб (`22`, `22,2222`, `http,https`); **`--logpath`** —
абсолютный путь, допустимы маски.

```
sudo asc fail2ban tune sshd --maxretry 3 --bantime 1d
```

### bans

```
asc fail2ban bans [--jail <jail>]
```

Список забаненных адресов: адрес, jail, когда забанен и до какого времени (`-`
для бессрочного).

### ban

```
asc fail2ban ban <ip> [--jail <jail>]
```

Банит один IP-адрес вручную (jail по умолчанию `sshd`). Бан вступает в силу
примерно через секунду.

### unban

```
asc fail2ban unban <ip> [--jail <jail>]
```

Снимает бан — со всех jail'ов, если не указан **`--jail`**. Сообщает, если адрес
не был забанен.
