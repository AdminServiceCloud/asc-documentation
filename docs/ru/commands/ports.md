# 🔌 asc ports

Показывает опубликованные порты по приложениям — сокращённая версия
[`asc app ports`](/ru/commands/app#ports) (root видит приложения всех пользователей).

## Использование

```
asc ports [-l | --listening]
```

## Опции

- **`-l`, `--listening`** — реально занятые порты хоста (DMN-103), а не то,
  что объявляют приложения: порты читаются напрямую из `/proc/net/*` и
  сливаются с атрибуцией по Docker-контейнерам и собственным API-портом
  демона.

## Без `--listening`

Каждое приложение и его порты host==container в виде таблицы.

## С `--listening`

Каждый реально занятый сокет хоста, по одному в строке — порт, протокол,
адрес и (когда удалось определить) владелец: приложение ASC, Docker-контейнер
или процесс. Порт, который объявлен установленным приложением, но пока не
занят (приложение остановлено), показывается зарезервированным, а не
выглядит свободным.
