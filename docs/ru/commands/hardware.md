# 🖥️ asc hardware

Показывает железо машины: физический сервер или виртуальная, процессор, плата, модули памяти, диски, видеокарты и текущую температуру каждого датчика.

## Использование

```
asc hardware [--json]
```

| Флаг | Значение |
|---|---|
| `--json` | Вместо таблицы напечатать один JSON-документ для скриптов |

Читается в самом процессе, как блок метрик в `asc status`, — запущенный демон не нужен. Без `--json` вывод — короткий отчёт:

```
Машина: физический сервер — ASUS System Product Name
Процессор: Intel(R) Xeon(R) E-2288G CPU @ 3.70GHz · сокетов: 1, ядер: 8 / потоков: 16 · 5.0 GHz
Плата: ASUSTeK COMPUTER INC. PRIME Z390-P · BIOS American Megatrends Inc. 2401
Память: 32.0 GiB
  DIMM_A1    16.0 GiB · DDR4 · 2933 MT/s · Samsung · M378A2K43DB1-CTD
Диски:
  nvme0n1      1.8 TiB  nvme    Samsung SSD 990 PRO 2TB
Видеокарты:
  0000:01:00.0  NVIDIA GeForce RTX 3090  24.0 GiB
    можно подключить к контейнеру
Температуры:
  cpu      cpu            Package id 0           47.0 °C
```

- **PCI-адрес** видеокарты (`0000:01:00.0`) — значение, которое принимает настройка приложения `gpus`: `asc app settings <id>`, категория `gpus`.
- На виртуальной машине строки DMI, модули памяти и датчики часто скрыты; в этих местах так и написано, а не подставлены выдуманные значения.
