# ⬇️ asc install

Установка из реестра (`<name>`, `<stack>` или `<stack>/<app>`, опционально с
`@<version>`) либо напрямую из git-репозитория (`https://`, `ssh://` или
`git@host:path`).

## Использование

```
asc install <spec> [--source <имя>] [--name <имя>] [--branch <ветка> | --tag <тег>] [--path <подкаталог>] [--image | --build]
```

## Опции

- **`spec`** — спецификация пакета или URL репозитория (позиционный, обязателен).
- **`--source <имя>`** — источник реестра для установки, если пакет
  предоставляют несколько (не используется при прямой установке из репозитория).
- **`--name <имя>`** — своё имя приложения, пропускает интерактивный запрос;
  команды принимают его наравне с id приложения.
- **`--branch <ветка>`** — ветка для checkout (только прямая установка из
  репозитория); конфликтует с `--tag`.
- **`--tag <тег>`** — тег для checkout (только прямая установка из репозитория);
  конфликтует с `--branch`.
- **`--path <подкаталог>`** — подкаталог манифеста внутри репозитория, для
  монорепо-пакета (только прямая установка из репозитория).
- **`--image`** — скачать готовый образ, если манифест предлагает и `image`, и
  `image-build`, пропуская интерактивный выбор; конфликтует с `--build`.
- **`--build`** — собрать образ локально, если манифест предлагает оба варианта,
  пропуская интерактивный выбор; конфликтует с `--image`.
