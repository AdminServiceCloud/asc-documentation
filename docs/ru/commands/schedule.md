# ⏰ asc schedule

Задачи по расписанию, которые исполняет демон: перезапуск ноды,
старт/стоп/рестарт/обновление приложения, бекапы, shell-команды и
HTTP-проверки. Как они вычисляются и хранятся — на странице модуля
[⏰ scheduler](/ru/cli/scheduler).

## Использование

```
asc schedule <действие> [аргументы]
```

Задачи хранятся в каталоге данных демона (на системной установке принадлежит
root) — выполняйте команды через `sudo`. Время — локальное время ноды, если не
указан `--utc`.

### list

```
asc schedule list
```

Список задач: расписание, действие, следующий и последний запуск, результат.
Задачи, которыми управляет платформа, помечены `(platform)`.

### add

```
asc schedule add <расписание> <действие> [флаги...]
```

Добавить задачу. `расписание` — `hourly`, `daily@HH:MM`, `HH:MM` или
cron-выражение из пяти полей `мин час день месяц день_недели`. `действие` —
одно из `node-reboot`, `app-start`, `app-stop`, `app-restart`, `app-update`,
`backup`, `shell`, `http`.

- **`--app <приложение>`** — приложение, к которому относится действие
  (обязательно для `app-*` и `backup`; для `shell` — необязательно, тогда
  команда выполняется в каталоге приложения от имени его владельца).
- **`--command <строка>`** — shell-команда (`shell`).
- **`--url <url>`**, **`--method <метод>`** (по умолчанию `GET`),
  **`--header 'Имя: значение'`** (можно несколько раз), **`--body <текст>`** —
  запрос (`http`).
- **`--storage <имя>`** (можно несколько раз), **`--keep <n>`** — хранилища и
  ротация бекапа (`backup`; по умолчанию — политика приложения, иначе `local`).
- **`--timeout <сек>`** — таймаут shell/http, по умолчанию 600, не больше 3600.
- **`--utc`** — считать расписание по UTC.
- **`--comment <текст>`**, **`--id <id>`** — заметка и явный id задачи (по
  умолчанию генерируется).

```
sudo asc schedule add daily@03:00 backup --app db --storage s3-main --keep 7
sudo asc schedule add "*/5 * * * *" http --url http://127.0.0.1:8080/health
```

### remove

```
asc schedule remove <задача>
```

Удалить задачу вместе с журналом запусков.

### enable

```
asc schedule enable <задача>
```

Включить выключенную задачу.

### disable

```
asc schedule disable <задача>
```

Выключить задачу, не удаляя её.

### run

```
asc schedule run <задача>
```

Выполнить задачу сейчас, на переднем плане, и напечатать результат (вывод
команды, код и тело HTTP-ответа). Запуск попадает в журнал задачи.

### runs

```
asc schedule runs <задача> [--limit <n>]
```

Последние запуски задачи, новые первыми (хранится до 50).
